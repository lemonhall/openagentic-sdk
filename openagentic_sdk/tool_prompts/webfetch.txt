- Fetches a public web page through Tavily Extract
- Requires `TAVILY_API_KEY`
- Returns extracted page content in markdown by default (or text when configured via env)
- Use this tool when you need readable page content from modern websites, including JS-heavy pages

Usage notes:
  - The URL must be a fully-formed valid URL
  - Only public HTTP(S) URLs are allowed; localhost/private network targets are blocked
  - Custom request headers/cookies are not supported
  - This tool is read-only and does not modify any files
  - Results may be summarized if the content is very large
